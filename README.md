# Student-_Grade_Analyser-correct-version-

## About the Project

Student Grade Analyzer is a Python-based project designed to analyze a student's academic performance.

The program calculates:
- Total marks
- Percentage
- Grade
- Pass/Fail status
- Highest-scoring subject
- Lowest-scoring subject

It also creates a bar chart to visualize subject-wise marks.

## Technologies Used

- Python
- Google Colab

## Features

1. Takes marks as input from the user.
2. Calculates total and percentage automatically.
3. Assigns a grade based on percentage.
4. Checks whether the student has passed all subjects.
5. Identifies the highest and lowest scoring subjects.

## Project Output

The program successfully analyzes student marks and generates a visual representation of the results.
